# Machine Learning Zoomcamp 2026

This repository contains homework solutions and course projects for the [Machine Learning Zoomcamp 2026](https://github.com/DataTalksClub/machine-learning-zoomcamp) course by DataTalks.Club.

## Course Structure

- [Module 1: Introduction to Machine Learning](./01-intro/) - What ML is, CRISP-DM, environment setup, NumPy and pandas
- [Module 2: Machine Learning for Regression](./02-regression/) - Car-price prediction with linear regression, feature engineering and regularization
- [Module 3: Machine Learning for Classification](./03-classification/) - Churn prediction with logistic regression and feature importance
- [Module 4: Evaluation Metrics for Classification](./04-evaluation/) - Accuracy, precision, recall, F1, ROC curves and AUC
- [Module 5: Deploying Machine Learning Models](./05-deployment/) - Serve models with Flask/FastAPI, pickle/onnx, Docker
- [Module 6: Decision Trees and Ensemble Learning](./06-trees/) - Random forest, gradient boosting (XGBoost), tuning
- [Midterm Project](https://github.com/DataTalksClub/machine-learning-zoomcamp/blob/main/cohorts/2026/projects.md) - End-to-end project (submission 9 November, peer review 16 November)
- [Module 8: Neural Networks and Deep Learning](./08-deep-learning/) - TensorFlow/Keras: image classification, transfer learning
- [Module 9: Serverless Deep Learning](./09-serverless/) - AWS Lambda with ONNX models
- [Module 10: Kubernetes and TensorFlow Serving](./10-kubernetes/) - Deploy with Kubernetes and TF Serving
- [Capstone Projects](https://github.com/DataTalksClub/machine-learning-zoomcamp/blob/main/cohorts/2026/projects.md) - Two qualifying projects for the certificate

Homework statements are copied verbatim from [`cohorts/2026/homework/`](https://github.com/DataTalksClub/machine-learning-zoomcamp/tree/main/cohorts/2026/homework) in the course repository; each file is then solved in place.
